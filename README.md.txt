
# Extended Tic-Tac-Toe AI

## 1. Introduction

Project xây dựng trò chơi Tic-Tac-Toe mở rộng
kết hợp các thuật toán trí tuệ nhân tạo.

## 2. Game Configuration

- Board size: 4x4
- Win condition: 4 consecutive marks
- Players: X and O
- Game type: Two-player zero-sum game
- Observation: Fully observable
- Environment: Deterministic

## 3. AI Agents

1. Random Agent
2. Heuristic Agent
3. Minimax Agent
4. Alpha-Beta Agent
5. MCTS Agent
6. DQN Agent

## 4. Technologies

- Python 3.11
- Jupyter Notebook
- NumPy
- PyTorch
- Pygame
- Matplotlib
- Pandas

## 5. Project Structure

- game/: Game Engine
- agents/: AI algorithms
- training/: Model training
- interface/: Game interface
- experiments/: Evaluation
- tests/: Unit tests

## 6. Run

Activate the project environment:

conda activate tictactoe-ai

Start Jupyter Notebook:

jupyter notebook
